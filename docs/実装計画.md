### 2.2 ディレクトリ構造

`アーキテクチャ.md` のディレクトリ構成に従う。Vite のエントリは以下の 4 つ。

| エントリ | ファイル | manifest.json 上の指定 |
|---|---|---|
| Service Worker | `src/background/service-worker.ts` | `background.service_worker` (`"type": "module"`) |
| Content Script | `src/content/content-script.ts` | `content_scripts[].js` |
| Popup | `src/popup/index.html` → `main.tsx` | `action.default_popup` |
| Offscreen | `src/offscreen/index.html` → `index.ts` | `chrome.offscreen.createDocument()` で動的生成 |

### 2.3 manifest.json

```json
{

  "version": "0.1.0",
  "description": "ページ内の動画・音声ストリームを検出して保存します",
  "permissions": ["downloads", "storage", "webRequest", "offscreen"],

    "service_worker": "src/background/service-worker.ts",

    {
      "matches": ["<all_urls>"],
      "js": ["src/content/content-script.ts"],
```

### 2.4 実装詳細

#### メッセージ定義 (`src/shared/messages.ts`)

全コンテキスト間通信の単一の窓口。判別可能ユニオンで定義し、受信側でネロー化する。

```typescript
import type { DetectedMedia, DownloadRequest, DownloadTask } from './types'

export type ContentToBackground =
  | { kind: 'media-element-detected'; media: Omit<DetectedMedia, 'id' | 'tabId'> }
  | { kind: 'page-metadata'; title: string; url: string }

export type PopupToBackground =
  | { kind: 'list-media' }
  | { kind: 'rescan' }
  | { kind: 'start-download'; request: DownloadRequest }
  | { kind: 'cancel-download'; taskId: string }

export type BackgroundToOffscreen =
  | { kind: 'fetch-and-assemble'; taskId: string; segmentUrls: string[]; initSegmentUrl?: string }
  | { kind: 'abort'; taskId: string }

export type OffscreenToBackground =
  | { kind: 'progress'; taskId: string; downloadedBytes: number; totalBytes?: number }
  | { kind: 'assembled'; taskId: string; objectUrl: string }
  | { kind: 'failed'; taskId: string; error: string }

export type BackgroundToPopup =
  | { kind: 'media-list'; media: DetectedMedia[] }
  | { kind: 'download-updated'; task: DownloadTask }
```

#### Offscreen Document の生成 (`src/background/download-manager.ts`)

Offscreen Document は同時に 1 つしか存在できないため、生成前に存在確認を行う。

```typescript
async function ensureOffscreenDocument(): Promise<void> {
  const existing = await chrome.runtime.getContexts({
    contextTypes: ['OFFSCREEN_DOCUMENT'],
  })
  if (existing.length > 0) return

  await chrome.offscreen.createDocument({
    url: 'src/offscreen/index.html',
    reasons: ['BLOBS'],
    justification: 'メディアセグメントの結合と Blob URL 発行のため',
  })
}
```

#### Popup の状態購読 (`src/popup/hooks/use-media-list.ts`)

popup は状態を所有しない。background が所有する状態を購読して描画するだけにする。

```typescript
import { useEffect, useState } from 'react'
import type { BackgroundToPopup } from '../../shared/messages'
import type { DetectedMedia } from '../../shared/types'

export function useMediaList() {
  const [media, setMedia] = useState<DetectedMedia[]>([])
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    const port = chrome.runtime.connect({ name: 'popup' })
    port.onMessage.addListener((message: BackgroundToPopup) => {
      if (message.kind === 'media-list') {
        setMedia(message.media)
        setIsLoading(false)
      }
    })
    port.postMessage({ kind: 'list-media' })
    return () => port.disconnect()
  }, [])

  return { media, isLoading }
}
```

## 3. 実装順序（Phase 1 の推奨順）

1. **コアロジック層から着手する。** `shared/` → `media/` → `processor/` の順。この時点で Unit テストが書け、ブラウザなしで検証できる
2. **background の検出パイプライン。** RequestDetector → MediaRegistry → バッジ更新。ここまでで「検出できているか」が観測可能になる
3. **content script の DOM 検出。** ネットワーク検出との統合・重複排除を確認
4. **popup の表示。** 検出結果の可視化。ここまでが「読み取り専用」の完成形
5. **direct ダウンロード。** `chrome.downloads` 直行の最短経路
6. **offscreen 経由の HLS(TS) ダウンロード。** SegmentFetcher → BlobAssembler → objectURL → `chrome.downloads`
7. **エラー表示・DRM 判定・ブロックリスト。** 対応外を明示する経路

各ステップ完了時に `pnpm verify` を実行する。
