# Video Download Helper スタイルガイド

Tailwind CSS に関するプロジェクト共通のスタイルルール。適用対象は Popup UI（`apps/extension/src/popup/`）。

Chrome 拡張のポップアップは通常の Web ページと寸法モデルが異なるため、Web アプリ向けの慣習をそのまま持ち込まないこと。

## 1. ポップアップの寸法: ビューポート単位を使わない

### ルール

- `h-screen` / `min-h-screen` / `h-dvh` / `h-svh` など **ビューポート単位（`vh` / `dvh` / `svh` / `lvh`）は使用禁止**
- ルート要素は **固定 px** で指定する（幅 `w-[420px]`、高さ `max-h-[600px]`）
- スクロールはルートではなく **一覧領域の内側** に持たせる（`flex-1 overflow-y-auto`）
- `calc()` 内でもビューポート単位を使わない

### 理由

Chrome のポップアップはコンテンツサイズに応じてウィンドウ自体が伸縮し、最大 800×600px でクリップされる。この環境では `100vh` はレイアウト前のコンテンツ高さを参照するため値が確定せず、「高さ 0 になる」「無限に伸びる」「スクロールバーが二重に出る」といった不安定な挙動を招く。ポップアップは可視領域がブラウザ UI に左右されないため、`dvh` を使う動機自体が存在しない。

### 寸法指定の比較

| 指定 | Tailwind クラス | 説明 |
|---|---|---|
| 固定 px | `w-[420px]` `max-h-[600px]` | ポップアップ推奨。要件定義 4.2 の寸法に一致 |
| `100vh` | `h-screen` | 値が確定せず不安定。**使用禁止** |
| `100dvh` | `h-dvh` | Web アプリ向けの解。ポップアップでは無意味。**使用禁止** |
| 内部スクロール | `flex-1 overflow-y-auto` | 一覧が長くなった場合の正しい逃がし方 |

### 具体例

```tsx
// NG
<div className="min-h-screen bg-gray-50">
<div className="h-dvh overflow-y-auto">

// OK
<div className="flex w-[420px] max-h-[600px] flex-col bg-surface">
  <Header />
  <div className="flex-1 overflow-y-auto">
    <MediaList />
  </div>
  <Footer />
</div>
```

### 備考

`html` / `body` にも高さ指定を置かない。`index.html` 側で `body { margin: 0; }` のみ与え、寸法はルートコンポーネントで完結させる。

## 2. カラーパレット: セマンティックトークンを使う

### ルール

- `text-[#333]` `bg-[#1a73e8]` のような **直値カラーの指定は禁止**
- Tailwind のテーマで定義したセマンティックトークン（`bg-surface` / `text-muted` / `bg-primary` / `text-danger` 等）を使う
- ダークモードは `darkMode: 'media'` とし、CSS 変数の切り替えで対応する。コンポーネント側に `dark:` を散らさない
- 状態色（成功 / 警告 / エラー / DRM 対応外）は色だけで区別せず、必ずテキストまたはアイコンを併記する

### 理由

要件定義 2.5 でダークモード対応とコントラスト確保が求められている。トークンに集約すれば、テーマ切り替え時の修正が CSS 変数 1 箇所で済み、コントラスト比の検証も定義箇所だけで完結する。色のみで意味を伝える実装はアクセシビリティ要件（WCAG 2.1 AA）を満たせない。

### 具体例

```css
/* popup/index.css — 定義はここに集約する */
@theme {
  --color-surface: #ffffff;
  --color-primary: #1a73e8;
  --color-muted: #5f6368;
  --color-danger: #d93025;
}

@media (prefers-color-scheme: dark) {
  @theme {
    --color-surface: #202124;
    --color-primary: #8ab4f8;
    --color-muted: #9aa0a6;
    --color-danger: #f28b82;
  }
}
```

```tsx
// NG
<button className="bg-[#1a73e8] text-white">
<span className="text-red-500">DRM</span>

// OK
<button className="bg-primary text-on-primary">
<span className="text-danger">
  <LockIcon aria-hidden="true" />
  DRM保護のため非対応
</span>
```

## 3. ページ由来テキストの折り返し

### ルール

- 動画タイトル・ページタイトルには `truncate`（1 行）または `line-clamp-2`（2 行）を必ず指定する
- URL 等の区切り文字を持たない長大文字列には `break-all` を指定する
- 折り返し指定のある要素の親には `min-w-0` を付ける（flex の子要素は既定で縮まないため）
- 省略表示した要素には `title` 属性で全文を補う

### 理由

表示する文字列はすべてページ由来であり、長さを制御できない。幅 420px 固定のポップアップでは、単一の長い URL が横スクロールを発生させてレイアウト全体を破壊する。折り返しはスタイルの好みではなく、外部入力に対する防御である。

### 具体例

```tsx
// NG
<div className="flex">
  <span>{media.title}</span>
  <span>{media.sourceUrl}</span>
</div>

// OK
<div className="flex min-w-0 flex-col">
  <span className="truncate" title={media.title}>
    {media.title}
  </span>
  <span className="break-all text-xs text-muted">
    {media.sourceUrl}
  </span>
</div>
```
